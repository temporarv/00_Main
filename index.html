Guardar directamente en GitHub

Para editar usuarios existentes, el token necesita Contents: Read and write en su repositorio. Para agregar uno nuevo, necesita el mismo permiso tanto en su repositorio como en 00_Main.

Para crear un usuario, primero crea su repositorio vacío (p. ej., usuario04) en GitHub. Esta aplicación crea usuario.txt allí y luego agrega el identificador a 00_Main/usuarios.txt. La creación del repositorio y la activación de GitHub Pages no son automáticas. El token permanece solo en el formulario y no se guarda; no compartas tokens.

Formato de usuario.txt: línea 1 = usuario; línea 2 = activ0/activ1; línea 3 = config0/config1; línea 4 = titular; línea 5 = URL; línea 6 = exactamente 4 palabras. usuarios.txt enumera todos los usuarios, incluso los inactivos. También se pueden leer archivos antiguos de cinco líneas; al guardar, se convierten al formato nuevo con activ1. Las líneas que empiezan por # en el listado son comentarios.
